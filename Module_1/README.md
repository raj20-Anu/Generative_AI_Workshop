# Module 1 – Prompt-Based AI System

## 📌 Objective
To build a simple prompt-based AI system that explains complex topics in different audience styles.

---

## 🧠 What This Module Does
- Accepts a topic from the user
- Applies creative prompt engineering
- Generates explanations in different personas such as:
  - Shakespearean style
  - Pirate style
  - Casual / bandit-style explanation

---

## 🛠 Concepts Covered
- Prompt engineering fundamentals
- Persona-based responses
- Creative AI generation
- Basic interaction with LLMs

---

## ▶ How to Run
```bash
pip install -r requirements.txt
python main.py
(make sure to use your API in .env)
